# Generic pilot data preparation

The next experiment has a **$10 additional ceiling**, approved 2026-09-20.
The dataset is frozen and ready for the bounded research pilot: 5,000 training,
500 validation and 1,000 test images, each with four questions. All 6,500 images
were decoded and hashed. No model quality result follows from data construction.

Use VQA v2, whose questions and ten answers per question originate from human
annotation. The official source publishes normalized answers, question IDs and
image IDs. The four question/answer ZIP files suffice to choose a subset before
fetching images. [Official downloads and format](https://visualqa.org/download.html).

VQA annotations are CC BY 4.0 and require attribution to the VQA Consortium.
Credit Goyal et al., *Making the V in VQA Matter*, CVPR 2017, and Antol et al.,
*VQA: Visual Question Answering*, ICCV 2015. The annotation license does not
replace the individual COCO/Flickr image licenses; preserve their source and
license records before training or redistribution.
[VQA terms](https://visualqa.org/terms.html),
[COCO terms](https://cocodataset.org/#termsofuse).

GQA remains a possible later evaluation source. Its questions are generated by
a rule-based engine from scene graphs, so this pilot uses VQA's direct human
answers instead. [Official GQA generator](https://github.com/dorarad/gqa).

## Build a candidate manifest

```bash
.venv/bin/python examples/features/diffusion_reads/evaluation/prepare_generic_pilot.py \
  --cache .vast-run/generic-pilot/vqa-cache \
  --output .vast-run/generic-pilot/data --download
```

This downloads only the four official question/annotation ZIPs. Per-file limits
prevent unbounded downloads; source SHA256 values are recorded. Without
`--download`, existing cache files are required. Output must be an empty
directory so a frozen manifest cannot be overwritten accidentally. Images are
not downloaded by this command: `images.jsonl` lists the selected COCO URLs.

The target is exactly 5,000 training images, 500 validation images and 1,000
test images, each with four questions: 20,000/2,000/4,000 questions. Selection
fails explicitly if eligibility cannot provide those counts. This is a sampling
target, not an assertion that the actual source has passed the filter.

The VQA training source is partitioned by image before selecting examples.
A seeded 60,000-image pool supplies training candidates. Answer option
vocabularies are fixed semantic categories, not estimated from answer frequencies.
Remaining training-source images supply validation candidates. Official VQA
validation-source images supply the pilot's untouched test candidates. The script
asserts disjoint image IDs. This does not establish absence of near duplicates
or absence from the pretrained backbone's original data.

Spatial questions are excluded from adapter training and calibration by a fixed
rule matching named spatial relations or questions beginning with “where”. At least
250 test images must contain a spatial question. The test split is marked for a
new prompt-wrapper template, which the training/evaluation runner must implement.
This is a coarse reserved task family; other training questions can still require
implicit spatial reasoning. Report it as such, not universal unseen-task coverage.

## Labels and the model interface

Each JSONL row contains `id`, `image`, `image_id`, `family`, `question`, `state`
and `target`. `question` follows the existing feasibility scorer's typed schema;
`target` maps option keys to human-answer vote fractions. `state` is empty and
contains no answer information. Source IDs and votes are retained for audit but
must never be interpolated into model prompts.

- Boolean answers use the two no/yes options.
- Integer counts from 0 through 15 use ordered score options. This is an ordinal
  proxy, not supervision for subjective quality or severity rubrics.
- Colours use a fixed palette; grey/gray are merged.
- Other answers use 4–16 options from fixed seasons, materials, rooms, sports,
  animals or vehicles vocabularies selected by question wording. An explicit
  alias table merges common plural forms and clear synonym variants. Questions
  with human answers outside the applicable vocabulary are rejected.

Examples require at least 80% agreement, with every answer represented in the
option set. The target retains minority votes rather than silently converting
them into certainty. Choice presentation order is seeded per question; training
should additionally reshuffle options and evaluate reversals. Score values remain
semantically ordered even when a model runner shuffles their letter labels.

These filters favour consensus and covered answer categories. They do not reproduce the
official VQA distribution or official VQA metric. Record majority-answer accuracy
and probability metrics separately, including sample counts by family/primitive.
Multiple alternatives can still be simultaneously visible; labels alone cannot
prove that all distractors are incorrect for the specific image.

The first candidate's random question-type answer distractors were rejected
after a fixed training-only audit found irrelevant alternatives and synonyms.
Examples included seasons offered alongside spoons/guitars and banana/bananas
as separate choices. The corrected rule uses fixed semantic categories. A second
training-only sample of 25 open-category questions had coherent answer categories;
this was an AI textual review, not human verification of image ground truth.
No test predictions informed either change. Test labels were used only by the
deterministic eligibility/sampling code.

Candidate v3 contains 20,000/2,000/4,000 questions. Its training primitives are
13,824 boolean, 3,544 count and 2,632 choice; test includes 257 questions matching
the reserved spatial rule. The initial narrow spatial rule yielded only 202
eligible spatial test images after the option correction. Expanding the rule to
include explicit “next to”, “inside”, “outside”, “under” and similar relations
restored the predeclared 250-image minimum without shrinking the test set.

## Image provenance and duplicate checks

The official COCO metadata archive is 252,872,794 bytes, SHA256
`031296bbc80c45a1d1f76bf9a90ead27e94e99ec629208449507a4917a3bf009`.
The documented Google Cloud metadata mirror returned 404; the primary image
hostname failed TLS hostname validation. The same public COCO bucket is
accessible at `https://s3.amazonaws.com/images.cocodataset.org/`; certificate
verification remains enabled. Source attribution and license records are read
from the official captions metadata, not guessed from filenames.

```bash
.venv/bin/python examples/features/diffusion_reads/evaluation/prepare_generic_pilot.py \
  --cache .vast-run/generic-pilot-prep/vqa-cache \
  --output .vast-run/generic-pilot-prep/candidate-v3 --audit-images \
  --image-cache .vast-run/generic-pilot-prep/image-cache \
  --coco-metadata .vast-run/generic-pilot-prep/annotations_trainval2014.zip
```

This fetches only selected images with 12 workers, three attempts per image,
4 MiB per-file limits and a 2 GiB cache ceiling. It validates decoding and records
SHA256, dimensions, 64-bit grayscale difference hash, URL and source/license
metadata. Set the trainer's image root to `--image-cache`, since manifest image
paths begin with `images/`. Exact hashes and cross-split difference-hash Hamming
distances of at most four flag duplicate candidates. This heuristic can miss
crops and other near duplicates. Use `--exclude-image-ids` with a JSON list to
remove flagged source IDs and rebuild an exact-size manifest in a new directory.

## Mandatory pre-training audit

New preparer output deliberately starts with status
`candidate_requires_image_license_dedup_and_distractor_audit`. The frozen pilot
has completed these checks with the limits below and is marked
`ready_for_bounded_research_pilot_with_documented_limits`.

1. Retrieve selected images with bounded downloads and retries. Record byte
   hashes, source attribution and image license metadata; validate image decoding.
2. Check exact and perceptual duplicates across partitions. Group likely matches
   and rebuild the deterministic manifest before inspecting model outputs.
3. Audit training/validation distractor examples by question family. Fix rules
   using those splits alone; freeze them before constructing final test examples.
   Any label-blind test integrity audit must be kept separate from model tuning.
4. Freeze manifests and hashes, verify every primitive and reserved task has
   sufficient examples, and measure representative sequence lengths. Compare
   expected training plus evaluation cost against the remaining $10 allowance.
5. Only then score the unadapted model, train adapters and run the predeclared test
   evaluation. Never select a model or tune distractors using test predictions.

The script has passed repository pre-commit checks and local behavioral checks
of target preservation, rejection, image selection and duplicate refill.

## Frozen pilot

Data directory: `.vast-run/generic-pilot-prep/final`; image root:
`.vast-run/generic-pilot-prep/image-cache`. These local artifacts are ignored by
Git. The manifest SHA256 is
`743963803186dedf2c3e4730bb3e34c7f00dc7e965d30b61be97fdd7f0913e6e`.
Image payload totals **982,755,843 bytes**. `upload-provenance.json` indexes the
manifest, metadata sources and hashes; `image-provenance.jsonl` records every
image's byte hash, original metadata and license. The upload allowlist must
include only those selected images and declared experiment files, never the
surrounding private `.vast-run` directory.

The initial image audit found five cross-split near-duplicate candidates
involving three training images, with no byte-identical images. Conservatively
excluding training IDs 572165, 482201 and 557342 and replacing them removed all
five flags. Validation and test files remained byte-for-byte unchanged. A full
repeat scan found no cross-split exact or dHash-distance-at-most-four candidates.
This is heuristic duplicate screening, not proof that no near duplicates exist.

Final question counts and primitive/family counts match candidate v3 above.
Every option set has 2–16 distinct options, includes all retained human-answer
votes and sums to one. All splits are image-ID disjoint and have exactly four
questions per image. All 25 textually reviewed training examples remain in the
final subset. Test predictions have not been generated or inspected during data
preparation.
